# fedorbell demo

Reply with one message that shows each feature once, in the current theme (read it with `node <plugin-root>/scripts/fedorbell.mjs show`), in this order: a table with the theme's status markers, a `flowchart`, a `sequenceDiagram`, a text figure, a `> [!NOTE]` callout, a code block with a language tag, a `$$` formula. Then render a bar chart with the `fedorbell-chart` skill. Add one caption line per item. [demo.md](./demo.md) is a ready-made sample; adapt it, do not paste it verbatim.
